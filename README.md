# AURA – Focus Timer

A simple focus timer designed to help me stay focused, take breaks, and manage my study sessions.

### Features
- Focus and break timers
- Start, pause, and reset controls
- Daily focus-time tracking
- Ambient sound options
- Minimal and responsive design

### Built With
- HTML
- CSS
- JavaScript
- Local Storage
- Web Audio API

### Run Locally
1. Clone this repository.
2. Open `Aura.html` in your browser.
3. Start focusing!

Built as a simple personal project to make focused work a little easier.
